Logbook interactive visual preview

1. Extract this ZIP.
2. Open index.html with Chrome or Edge.
3. Use the left menu to switch between Dashboard, household data, assistance history, module samples, and triage.
4. The preview contains demo data only and does not connect to your Aiven database.
5. Search boxes and the red/yellow/green triage filters work locally in this preview.

The ASP.NET Core MVC project is in the separate Logbook_Priority_Search.zip.
